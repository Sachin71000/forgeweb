# ForgeWeb verification report — 25 October 2026

## Follow-up: approved Gemini-first implementation

- Gemini now handles React source, standalone preview, and Python backend generation; Groq and OpenRouter remain fallbacks.
- Invalid JSON and MAX_TOKENS responses receive one bounded retry. Safety stops and account failures are not treated as repairable JSON.
- React source and preview are requested separately after a live response exceeded the token budget.
- Temporary DNS/connection-establishment failures receive bounded retries. Connection resets are not automatically replayed because the provider may already have accepted a billable request.
- Fixed a persistence race: published in-memory state now advances only after the snapshot is saved successfully. A regression test verifies recovery after a failed write.
- Updated regression suite: 51 tests pass; TypeScript checks pass.
- Latest split-generation live test: build_377a6bc293824b5ea37e failed with a Gemini connection reset and DNS failures on both fallbacks. No files were published. A working live preview has NOT been verified. The original account limits may still apply after connectivity stabilizes.

The results below describe the preceding test pass and are retained as historical evidence.

## Verdict

The control-plane regression suite, TypeScript checks, and production build pass. End-to-end generated-application acceptance remains blocked by provider account limits. This is not a production-readiness certification or a claim of zero defects.

## Reproduced failures and changes

- All three providers originally failed with EACCES when the dev server ran inside the restricted execution sandbox. Provider hosts responded outside it. The server was restarted with approved network access; TLS verification was not disabled.
- Provider errors now distinguish network permissions, DNS, TLS, connection timeout, and reset/refusal without exposing raw error details or configured credentials.
- HTTP 404 no longer receives unnecessary retries. Transient 5xx retries are bounded and cancellation interrupts backoff. Quota and authentication failures are not rapidly retried.
- Invalid response-envelope JSON is reported as invalid JSON rather than a connectivity failure.
- Live frontend generation omitted the package dev script. The generation instructions now explicitly require runnable scripts and dependencies; model validation failures receive at most one repair attempt. Failed repair does not substitute a template.
